# 実機確認結果

2026年10月17日、所有者が本配布版の共通カーネルを使い、PW-SH1〜PW-SH7すべてで音声再生が正常に動作することを確認しました。

| 機種 | 音声チップ | 共通カーネルでの再生 |
|---|---|---|
| PW-SH1 | YMU818B | 確認済み |
| PW-SH2 | YMU818B | 確認済み |
| PW-SH3 | BU26154 | 確認済み |
| PW-SH4 | BU26154 | 確認済み |
| PW-SH5 | BU26154 | 確認済み |
| PW-SH6 | BU26154 | 確認済み |
| PW-SH7 | BU26154 | 確認済み |

PW-SH1はSSHから共通カーネルの起動、YMU818B用2モジュールの自動ロード、音声カード登録、起動サービスの成功を確認し、その後所有者が実際の再生音を確認しました。PW-SH2〜SH7は所有者から正常動作の報告を受けています。各機種の詳細ログは今回収録していません。

静的確認では7機種のDTBと音声ドライバーのCソースが、従来の動作確認済み配布物とバイト単位で一致しています。変更の中心はYMU818Bのモジュール化、カーネルリリース名と起動設定です。ビルドログにwarning/errorはありません。音声モジュール3個のvermagicも共通カーネルと一致しています。

44.1 kHz / S16_LE / ステレオの本体スピーカー再生を対象としています。YMU818Bのハードウェア音量調整は未実装です。録音、ヘッドフォン、サスペンド復帰は今回の全機種共通の確認対象に含めません。
